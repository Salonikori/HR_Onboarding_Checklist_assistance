# OnboardAI Proper Dynamic v2

Employee and HR portals share the same FastAPI backend and SQLite database.

Employee:
- individual login
- live checklist
- Complete button updates the database
- natural-language onboarding query
- dynamic transformer sentence-embedding + cosine similarity against approved guide text
- query is stored as Pending Review for HR

HR:
- Dashboard summary
- Employees: all 500 employees, search, live completion, pending/overdue counts
- Employee drawer: full checklist, remaining tasks, previous queries
- Cases: employee-submitted queries
- Review Queue: queries waiting for HR
- Audit Info: logins, task completions, queries, HR reviews
- Approve/Override with reviewer note

Email notifications (new):
- A background scheduler automatically emails employees a reminder for any
  task that is overdue or due soon — no HR action required. It runs once at
  startup and then on a fixed interval (default every 60 minutes).
- HR can also trigger emails manually via API:
  - `PATCH /api/hr/employees/{employee_id}/email` — set/update an employee's email
  - `POST /api/hr/employees/{employee_id}/send-welcome-email` — (re)send the onboarding task-assignment email
  - `POST /api/hr/employees/{employee_id}/send-reminder` — send an immediate reminder email
- If SMTP isn't configured, emails are written to `data/email_outbox.log`
  instead of being sent, so the whole flow can still be demoed/tested without
  a real mail server.
- Configure real delivery by copying `.env.example` to `.env` in the project
  root and filling in your SMTP details.
- `data/employee_login_credentials.csv` now has an `email` column. It ships
  with placeholder `@example.com` addresses for all 500 demo employees —
  replace an employee's email (via the CSV before first run, or the
  `PATCH .../email` endpoint afterwards) with a real address to test delivery.

The CSVs are seed/reference data. The live state and query results are stored in `onboarding.db`.

## Run backend
```powershell
cd backend
python -m venv venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
cd ..
python -m uvicorn backend.main:app --reload
```

## Run frontend
```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```
